\section{梯度下降解多元线性回归}
\label{sec:chapter2}

\subsection{多元线性回归}

多元线性回归是一元线性回归的推广，其输入包含多个特征 $x_1,x_2,\cdots,x_n$. 给定数据集：
\[
\left\{\left(x_1^{(i)},x_2^{(i)},\cdots,x_n^{(i)},y^{(i)}\right),\;i=1,2,\cdots,m\right\}
\]
相应的回归模型也包含多个参数 $\theta_0,\theta_1,\cdots,\theta_n$：
\[
h_\theta(x)=\theta^Tx=\theta_0x_0+\cdots+\theta_nx_n
\]
为表示方便，这里假定 $x_0$ 恒等于 $1$，且记 $\theta=(\theta_0,\cdots,\theta_n)^T,\;x=(x_0,\cdots,x_n)^T$.


\subsection{梯度下降解多元线性回归}

\paragraph{代码函数及其梯度}

与一元线性回归类似，定义代价函数为均方误差：
\[
J(\theta)=\frac{1}{2m}\sum_{i=1}^m\left(\theta^Tx^{(i)}-y^{(i)}\right)^2
\]
其关于参数向量的梯度为：
\[
\frac{\partial J}{\partial \theta}=\frac{1}{m}\sum_{i=1}^m\left(\theta^Tx^{(i)}-y^{(i)}\right)x^{(i)}
\]
因此，梯度下降的参数更新公式为：
\[
\theta:=\theta-\alpha\cdot\frac{\partial J}{\partial \theta}
\]
反复执行上述更新，直至参数或代价函数收敛。


\paragraph{特征缩放与标准化}

当不同特征的取值范围相差较大时，代价函数的等高线会较为狭长，梯度下降可能需要更多次迭代才能收敛。为改善收敛速度，可以对各个特征进行标准化：
\[
x_i^{(j)}:=\frac{x_i^{(j)}-\mu_i}{\sigma_i}
\]
其中，$\mu_i=\frac{1}{m}\sum_{j=1}^m x_i^{(j)}$ 是样本均值，$\sigma_i^2=\frac{1}{m-1}\sum_{j=1}^m\left(x_i^{(j)}-\mu_i\right)^2$ 是样本方差。标准化后，样本均值为 $0$，方差为 $1$，不同特征具有相近的尺度，有利于梯度下降稳定而快速地收敛。


\subsection{代码实现}

以下代码中，\texttt{Normalization} 函数用于标准化数据，\texttt{J} 函数用于计算 $J(\theta)$，\texttt{partJ} 函数用于计算 $\frac{\partial J}{\partial\theta}$，\texttt{GradientDescent} 函数则负责执行梯度下降。

\begin{lstlisting}[language=Python]
import numpy as np
import matplotlib.pyplot as plt

alpha = 0.01
iteration = 10000
Z = []

def Normalization(data):
	return (data - data.mean(axis = 0)) / data.std(axis = 0, ddof = 1)

def J(T, X, Y):
	res = 0
	for i in range(m):
		res += (np.matmul(T.T, X[i:i+1, :].T) - Y[i:i+1, :]) ** 2
	res /= 2 * m;
	return res

def partJ(T, X, Y):
	res = np.zeros((n, 1))
	for i in range(m):
		res += (np.matmul(T.T, X[i:i+1, :].T) - Y[i:i+1, :]) * X[i:i+1, :].T
	res /= m
	return res

def GradientDescent(X, Y):
	T = np.zeros((n, 1))
	for t in range(iteration):
		T = T - alpha * partJ(T, X, Y)
		Z.append(J(T, X, Y)[0][0])
	return T

data = np.genfromtxt("ex1data2.txt", delimiter = ',')
(m, n) = data.shape
data = Normalization(data)
X = np.column_stack((np.ones((m, 1)), data[:, :-1]))
Y = data[:, -1:]
T = GradientDescent(X, Y)
print(T)

p1 = plt.subplot(111)
p1.plot(range(1, iteration+1), Z)
p1.set_xlabel('Iteration')
p1.set_ylabel('Cost')
plt.show()
\end{lstlisting}

最终得到的参数为：$\theta=(-1.11051830\times10^{-16},8.84765988\times10^{-1},-5.31788197\times10^{-2})^T$.
